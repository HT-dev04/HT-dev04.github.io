# ht-dev04.github.io

Meu portfólio: https://ht-dev04.github.io

Uma página em HTML e CSS, sem framework e sem etapa de build. O `auditoria.js` é a demonstração da auditoria encadeada por hash do Avontz Docs (SHA-256 pela Web Crypto, no navegador). As imagens dos cards são capturas reais das páginas dos produtos. O gráfico de commits é um SVG estático gerado a partir do `git log` dos repositórios da Avontz.

Fontes: Newsreader, Hanken Grotesk e IBM Plex Mono (Google Fonts).
